🎯 FEATURES IMPLEMENTED
════════════════════════════════════════════════════════════════════════════════

✅ Positive CTS Extraction
   - Sliding window approach (30-nt windows, 5-nt step)
   - Flanking context (5nt upstream/downstream)
   - Top K selection by binding energy
   - CLIP-based extraction (framework ready)

✅ Negative Pair Generation
   - Random sampling from non-targets
   - Configurable negative:positive ratio
   - Ensures no overlap with positives

✅ Hard Negative CTS Extraction
   - Energy-based filtering (ΔG threshold)
   - Thermodynamically stable but non-functional
   - Top K selection per pair

✅ ViennaRNA Integration
   - Duplex binding energy calculation
   - cofold implementation
   - Mock version for testing
   - Real ViennaRNA support

✅ User Experience
   - Progress bars (tqdm)
   - Comprehensive logging
   - Detailed statistics output
   - Error handling
   - Input validation

✅ Configurability
   - Window size, step size, flanking
   - Top K sites (positive and negative)
   - ΔG threshold
   - Negative ratio
   - All parameters customizable via CLI
